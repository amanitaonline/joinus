How it works

Everything runs in your browser. Nothing is uploaded.

The tabs

Make Transparent
Removes a white or colored backdrop.
Clean Up Edges
Fixes halos, specks, pinholes, and soft edges.
Sticker Outline
Adds an outline and drop shadow.
Separate Inks
One plate per ink (spot, CMYK or RGB), with underbase, registration marks, and a zip.
Reduce Colors
Fewer colors and smaller files, as indexed PNG, WebP, or JPEG.
Vectorize
Flat, few-color art to a clean SVG.
Print Prep
Mirror, upscale, trim, and DPI and size.
Gang Sheet
Gang sheet from all loaded files.
Garment Mockup
See the design on a tee.

Quick recipes

  • Dark garment (DTF or screen): Make Transparent, then Clean Up Edges with a little defringe, then Separate Inks with the underbase on, then download the zip.
  • Sticker or web file: Make Transparent, then Sticker Outline, then Reduce Colors with indexed PNG.
  • Gang sheet: load all designs, set the DPI in Print Prep, then open Gang Sheet and download.

Handy bits

  • By default the tabs build on each other, so the preview shows the result of all of them. Tick Tabs work separately and each tab starts from your original image and uses only its own settings.
  • The before / after box is above the tabs. Presets are at the bottom.
  • The color slider and light / dark button are up top.
  • Undo / Redo (also Ctrl+Z and Ctrl+Shift+Z) steps back through your recent settings changes. The History list jumps straight to any step.
  • Nearest ink match sits under the spot colors in Separate Inks. It suggests a Pantone-style code for each color and adds an ink list to the plates zip.
  • Save project stores your images and settings in one .guppy file. Open project puts everything back.
